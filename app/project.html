Шаг 1 · исходные данные

Данные

Одна строка данных создаёт одну страницу. Добавьте таблицу и проверьте, что важные колонки заполнены.

Источник данных
Выберите удобный способ загрузки. Доступные варианты помечены ниже.
Файл CSV или Excel Колонки файла станут фактами строки автоматически. заглушка нужен загрузчик таблиц
Google Sheets Таблица остаётся живой: поправили строку — перегенерили страницу. заглушка нужен доступ к листу
Внешний API Для типа «Статус с датой» данные должны обновляться сами. заглушка нужен URL и расписание
Вставить руками По строке на ключ, факты через точку с запятой. работает быстрый старт
Строки данных
Первое значение — ключ страницы. Дальше — факты вида колонка=значение, именно они и делают страницы разными.

    Как это работает
    1. Мы копируем готовые страницы на отдельный поддомен — боевой сайт не затрагивается.
    2. Клиент открывает ссылку, вводит пароль и попадает на оглавление со всеми страницами.
    3. Доступ запоминается в браузере на 30 дней; новый пароль отключает всех, кто уже вошёл.
    4. По истечении срока черновик удаляется с сервера автоматически.
